# Character data (zh.json, ja.json)

Generated by `scripts/build-characters.mjs` for the characters the courses use. Sources:

- **Unicode Unihan database** (radical-stroke index `kRSUnicode`, `kTotalStrokes`,
  `kMandarin`, `kDefinition`), read through the `kanji-inspector` npm package.
  © Unicode, Inc., [Unicode License v3](https://www.unicode.org/license.txt).
- **Chinese characters decomposition** table from Wikimedia Commons (parts of Chinese
  characters), through the `chinese-characters-decomposition` npm package.
  [CC BY-SA](https://commons.wikimedia.org/wiki/Commons:Chinese_characters_decomposition).
- **KANJIDIC** (on / kun readings, meanings, stroke counts, JLPT level, school grade), © the
  Electronic Dictionary Research and Development Group, [CC BY-SA 4.0](https://www.edrdg.org/edrdg/licence.html),
  through the `kanji-data` npm package.
- **KanjiVG** (parts of Japanese kanji, from the kanji trees in the `kanji` npm package),
  © Ulrich Apel, [CC BY-SA 3.0](https://kanjivg.tagaini.net/).
- English names of the Kangxi radicals from **HanziJS** (`hanzi` npm package), MIT.

The derived files are shared under the same CC BY-SA terms.

The plan named Make Me a Hanzi for Chinese parts; it isn't published on npm (and this
build runs offline), so the Wikimedia table, which covers the same characters, is used.
Stroke-order shapes (public/strokes) come from Make Me a Hanzi / AnimCJK as before.
